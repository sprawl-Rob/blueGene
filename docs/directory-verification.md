# Directory verification

Starter region: Massachusetts, New Hampshire and Vermont, with U.S. national collections and links for overseas origins. This is intentionally incomplete geographic and temporal coverage. No private export was used to choose a region.

Seed version 3: 76 entries; 26 collections across 10 providers; 12 local repositories across 3 states, 8 with scoped official-page checks. Status totals: link checked: 23, Needs verification: 19, coverage checked: 34.

Checks were performed on official public pages on 2026-10-05. “Link checked” verifies availability/identity only. “Coverage checked” refers to the recorded verification scope, not an authenticated search or exhaustive holding review. An access badge records a stated route; it does not guarantee a particular image is accessible. No prices, partnerships, APIs or record counts were inferred.

The complete machine-readable metadata is in [seed-directory.json](seed-directory.json). Unavailable or blocked checks remain Needs verification. FamilySearch search, Full-Text, Catalog and Wiki are separate discovery capabilities. Providers do not inherit collection coverage. Major unresolved checks include some Library of Congress pages, FamilySearch Wiki, commercial providers, NH/VT agency pages and overseas portals.

Maintain entries in Resource explorer → Details → Edit / verify / archive. Include a date, official reference and explicit scope when changing verification status. Seed refreshes update unchanged fields, retain local overrides and record seed conflicts. Archive an entry to hide it from routine suggestions without deleting it.
