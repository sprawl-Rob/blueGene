# Synthetic fixtures

Every person, source and excerpt here is invented. These are handcrafted compatibility cases, not actual exports produced by Ancestry, RootsMagic or Family Tree Maker. Vendor-style headers/custom tags exercise preservation only and do not establish vendor compatibility.

`fictional-demo.ged` covers Unicode, conflicting approximate dates, multiple marriages, adoptive/unspecified relationships, source/citation references, notes, custom markup and a missing media path. The RootsMagic and Family Tree Maker variants change exporter headers and retain the same edge cases. `synthetic-gedcom7.gdz` supplies the same fictional hierarchy in UTF-8 GEDCOM 7 with matching local TXT media. Automated tests also build hostile archives in temporary storage.
